# 공공자전거 대여 시스템

> 원본: `original/AA_SharingBycle_1.jpg`

- 공공 자전거 대여 시스템은 **전국 5만 개 대여소**의 자전거 **대여, 반납, 요금 정산**과 **운영 관리**를 지원함
- 연동 대상은 대여소의 장비들(**인식 리더기, 거치대 잠금장치, 거치대 카메라, 키오스크**) 및 **결제 대행 시스템**임

## 대여소 구성도 (그림 설명)

| 구성 요소 | 역할 |
|---|---|
| 키오스크 | 거치대별 안내 화면 |
| 거치대 카메라 | 파손 촬영 |
| 이용자 | 앱으로 QR 스캔 → 대여 |
| 인식 리더기 | 태그 인식 → 반납 시작 |
| 잠금장치 | 잠금 확인 → 반납 확정 |
| QR 코드 · 식별 태그 | 자전거에 부착 |
| 정비 필요 자전거 | 대여 차단 대상 |

- 범례: ● 대여 가능 / ● 정비 필요 (대여 차단) / ○ 빈 거치대
