## 슬라이드 2 — 실습 2: 요구사항 명세

- OOO 전자 칠판 "**소프트웨어**"를 외부 회사를 통해 개발하려는 상황
- OOO 전자 칠판에 대한 상세 **소프트웨어 요구사항을 명세**해 봅시다. **(1시간)**
  - 소프트웨어 개발사업 제안요청서에 넣을 **소프트웨어** 요구사항 명세
  - 조별로 8개~12개 요구사항 명세 → 개인당 2개 정도 요구사항 명세
    - 가능하면 기능 요구사항 1개, 비기능 요구사항 1개 명세 추천
  - 실습 1에서 도출된 요구사항 활용 가능
  - "공공SW사업 제안요청서 작성을 위한 요구사항 상세화 실무가이드라인"의 표 형태 템플릿 활용 가능
- 소프트웨어 요구사항 명세 결과 리뷰 **(30분)**

---

### 실습 요약

| 항목 | 내용 |
|---|---|
| 대상 | OOO 전자 칠판 소프트웨어 (외부 개발사에 발주) |
| 산출물 | 제안요청서(RFP)에 들어갈 소프트웨어 요구사항 명세 |
| 분량 | 조별 8~12개 (개인당 약 2개: 기능 1, 비기능 1 권장) |
| 참고 | 실습 1 도출 요구사항, 공공SW사업 요구사항 상세화 실무가이드라인 템플릿 |
| 시간 | 명세 작성 1시간 + 결과 리뷰 30분 |
